Coin Flip Game

A simple coin flipping game built with HTML, CSS, and JavaScript. When you click the coin, it flips with an animation and randomly lands on either heads or tails.

What I Learned

How to use Math.random() to generate random outcomes

How to create and control animations using CSS @keyframes

How to add and remove CSS classes dynamically with JavaScript

How to use setTimeout() to delay actions until an animation finishes

How to handle click events and update image sources dynamically
